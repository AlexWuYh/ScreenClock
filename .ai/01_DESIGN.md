# 设计

实现时以本文为准。和里程碑冲突时，先改文档再改代码。

## 已定决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 客户端 | Kotlin + Jetpack Compose，单 Activity，单模块 | 钟面是一块自适应画布，不需要多模块 |
| 最低系统 | minSdk 26，JDK 17。compileSdk / targetSdk / Compose BOM 用开工时的稳定版，写进 version catalog | 文档不锁会死版本号 |
| 应用 id | `app.screenclock` | 发布前可以改，改时同步清单和文档 |
| 外观 | 只有深色钟面 | 床头和桌面都靠暗底；亮色主题会把烧屏和夜间体验重做一遍 |
| 小时制默认 | 跟随系统 | 设置里可以改成固定 12 或 24 |
| 天气 | Open-Meteo 公开接口，手动城市为主 | 平板常常没有可用的卫星定位；无密钥 |
| 农历 | `cn.6tail:lunar` | 闰月和大小月不自己维护 |
| 专注计时 | 保存结束时刻 | 旋转、重建、进程重启都从同一时刻计算 |
| 屏保 | 一轮然后卸下武装 | 按产品要求「运行一次」。到时停住，有人再碰屏幕才重新计时 |
| 翻页外观 | 两位共用一块页片，像 FliTik。翻折是 FlipClock 的两段式。配色是墨黑 | 一位一张更碎。照片背景和自由取色不进 v1 |
| 第二主题 | 灯管。换分时亮一下，然后回到暗 | 和翻页一样，只在数字变化时动。慢指针留到 M7 |
| 仪式远日期 | 剩余不少于 24 小时，主角是天数。最后 24 小时才翻时分秒 | 远日期翻秒会变成计时器 |
| 农历表单 | 选择时就预览下一次公历日期。找不到则不能保存 | 避免空表选错闰月 |
| 语言 | 简体中文 | 英文放到 M7 以后 |

## 钟面

翻页主题的颜色见下文「翻页」。灯管主题用近黑底和暗琥珀光。日期、天气、纪念日条都用 `#A39E96`，不进页片。控制层是一层很轻的暗色遮罩。不用默认紫色，不用渐变英雄区。

主屏内容：

- 时间：必须有。
- 日期：默认开，可关。放在页片上方，居中，一行。中文环境为「M月d日 周X」。M6 起，若当天是法定节假日，接在星期后面，例如「10月1日 周四 · 国庆节」。只取一个短名称，不展示宜忌。
- 天气：M3 之后，默认关。
- 纪念日条：M6 之后，只有置顶项存在且未过期时出现。文案形如「距妈妈生日 86 天」。不足 24 小时写成「距妈妈生日 5 小时」。当天写成「今天 · 妈妈生日」。

主屏不显示秒。秒的翻页只在专注页，以及仪式页的最后 24 小时。

### 布局槽

用 WindowSizeClass 的宽度，而不是用「是不是平板」写两套页面。

| 宽度 | 摆法 |
|------|------|
| Compact，竖屏 | 两块页片上下叠放，小时在上、分钟在下，尽量占满安全区宽度。日期在页片上方 |
| Compact，横屏 | 两块页片同一行。日期仍在上方 |
| Medium / Expanded | 页片更大，排列规则不变。横屏平板是主构图 |

天气和纪念日条合成页片下方的一行。两者都在时用间隔号分开。只有一样时不留空位。

所有档位都避开显示挖孔和系统栏的安全区。翻页卡片不可被挖孔切掉。

旋转时 ViewModel 持有状态。翻页进行到一半若发生旋转，直接落到新数字，不接一段残缺动画。

### 控制层

点钟面空白处：显示「设置」「专注」「纪念日」。约 4 秒无操作，或再点空白处，收起。

点这些按钮进入对应页面，不在钟面上展开复杂面板。M0 可以只有按钮没有目的页。M5 之前「专注」可以不可用。M6 之前「纪念日」可以不可用。不可用时不要留一个点了没反应的按钮，直接不放。

系统栏保持隐藏。用户从边缘滑出时，系统可以临时显示系统栏。应用自己的控制层不靠系统栏。

### 翻页

默认主题，配色名「墨黑」。一块页片装两位数字：钟面是小时一块、分钟一块。这是 FliTik 的页片分组。翻折动作仍按 FlipClock：中缝对半，上半先折下，下半再折上。

自己用 Compose 绘制。不复制 FlipClock 的 `flipclock.ttf`、截图或 SDL 源码，不复制 FliTik 的图片、字体和音效。小时制在设置里。主屏不出现秒页片，也不要闪烁冒号。12 小时制的上午/下午用页片外的小字，放在页片组的一侧。

静止时：

| 部分 | 值 |
|------|----|
| 背景 | `#000000` |
| 页片 | `#333333` |
| 数字 | `#FFFFFF` |
| 中缝 | 横贯页片的细线，左右边缘各有一个小轴点 |
| 圆角 | 约为页片短边的 8% |
| 页片间距 | 两块页片之间留出明显空隙，大约一块页片宽度的 8%–15% |

中缝切过两个数字的字身。上半页和下半页各自裁切。某一位变化时，整块页片一起翻，不把两位拆开。`10:59` 到 `11:00` 时，小时和分钟两块都翻。

翻折两段，总时长约 400ms：

1. 旧数字的上半绕中缝向下折，露出新数字的上半。
2. 新数字的下半再从中缝向上折到位。

这不是交叉淡化，也不是整张页片绕竖轴翻转。系统「动画时长缩放」为 0 时，直接换成新数字。

TalkBack 忽略页片装饰，时间作为一个控件读出，例如「14点30分」或「下午2点30分」。

主题和配色分开存。v1 的翻页只有「墨黑」。以后加素白页片时，不重写翻折。

### 灯管

M2。同一组槽、同一种横竖屏排列，不画页片。设置里用两块大预览选择翻页或灯管，预览本身是缩小的钟面，不用下拉框。选中项用一条细的暖色描边。

数字是玻璃管：近黑底上的暗琥珀 `#E6A15C`，静止时亮度低，仍要能读。换分时，变化的那几位在约 700ms 内亮起再回到暗，不循环。系统动画时长为 0 时不播这下亮起，数字直接变为新值。中文日期仍用系统无衬线。

## 小时制

设置三项：跟随系统、12 小时、24 小时。持久化。

格式函数是纯函数：输入本地时间、模式、系统是否为 24 小时，输出钟面数字和读屏文案。单元测试锁住正午、午夜、上午 1 点和下午 1 点。

## 天气

一行。紧凑宽度是 `晴 18°`。扩展宽度在同一行加上当日最高和最低：`晴 18° · 26° / 14°`。最高和最低缺一则不加这段。不要预报列表。温度取最近的整数摄氏度。

城市搜索走地理编码。用户点选一条结果后保存显示名、纬度、经度。重名城市要带上地区或国家，供人分辨。点选结果会关掉「使用当前位置」，城市换成这一条。

「使用当前位置」取一次粗略坐标。允许的主机没有反向地理编码，所以不把坐标交给别的服务。取到坐标后，显示名记为「当前位置」，纬度和经度照常保存，之后按这对坐标刷新。没取到位置则保留原来的城市。流程的其余部分见安全文档。

WMO 天气代码映射成短中文：0 和 1 晴，2 多云，3 阴，45 和 48 雾，51、53、55、56、57 毛毛雨，61、63、65、66、67 雨，71、73、75、77 雪，80、81、82 阵雨，85 和 86 阵雪，95、96、99 雷暴。未知代码不编现象词；有温度就只显示温度，扩展宽度仍可加上高低温。映射表放在纯 Kotlin 里做测试。

缓存记录温度、代码、高低温和获取时间。年龄不满 30 分钟不刷新。满 30 分钟，或本机时间早于获取时间，视为过期。

## 防烧屏

设置：

| 项 | 默认 | 范围 |
|----|------|------|
| 开关 | 关 | 开 / 关 |
| 无操作多久后启动 | 5 分钟 | 1–60 分钟 |
| 每次运行多久 | 2 分钟 | 10 秒–30 分钟 |

界面文案用「无操作多久后启动」。这就是需求里的「误操作时长」。

### 状态

| 状态 | 含义 |
|------|------|
| `Off` | 功能关闭 |
| `Armed` | 正在累计无操作时间 |
| `Running` | 屏保运行中 |
| `Spent` | 本轮已结束，还没有新的触摸来重新武装 |

转移：

| 从 | 事件 | 到 |
|----|------|----|
| `Off` | 用户开启 | `Armed` |
| `Armed` | 无操作达到设定时长，且当前不在专注或仪式页 | `Running` |
| `Armed` | 有触摸 | `Armed`，计时清零 |
| `Running` | 本轮时长到了 | `Spent` |
| `Running` | 有触摸 | `Armed`，计时清零，屏保结束 |
| `Spent` | 有触摸 | `Armed`，计时清零 |
| 任意开启状态 | 用户关闭功能 | `Off` |
| `Armed` 或 `Running` | 进入专注或仪式 | 退出屏保，暂停。离开那些页面时回到 `Armed` 并清零 |

`Spent` 不会自己进入 `Running`。这就是「运行一次」。

屏保内容仍是当前主题的时间，在安全区内沿一条缓慢路径移动，亮度不提高。功能开启且状态不是 `Running` 时，静止钟面做 1–2px 的慢漂移。功能关闭时位置固定。

漂移是半径 1.5px 的圆，60 秒一圈，位移长度始终是 1.5px。屏保在调用方给出的行程框里走利萨如曲线，48 秒一圈，从中心出发。紧凑宽度行程 12dp，扩展宽度 24dp，不超过页片四周已有的留白。这两段位移都不重启翻页或灯管亮起。暂停时钟面不在前台，不做漂移。

暂停不只写在专注和仪式上。设置页打开，或宿主不可见（离开应用、屏幕关掉），用同一个暂停。两处都暂停时，只结束其中一处不会重新计时。最后一处暂停结束时：当时是 `Armed` 或 `Running`，就回到 `Armed` 并清零；`Spent` 和 `Off` 保持不变。进入暂停时若正在 `Running`，先退出屏保，这一轮不算走完。

无操作时长按分钟取整，范围 1–60。运行时长按 10 秒取整，范围 10 秒–30 分钟。越界值在进入状态机前夹紧。屏保中的第一次点按只结束本轮，不打开控制层。

状态机放在 `domain`，用虚拟时钟测试，不睡真的几分钟。

## 专注

从控制层进入。先选 25 分钟、50 分钟或自定义分钟数（1–180），再开始。

开始时写入 `endEpochMillis = now + duration`。界面剩余时间一律是 `end - now`，不小于 0。这一页只有页片：不足 1 小时用分钟和秒两块，有小时则用时、分、秒三块。不显示日期、天气、纪念日，也不画波形。到 0 进入完成态：页片停在 0，直到用户点一下。点一下清除结束时刻并回钟面。

提前结束：长按约 600ms。短按无退出效果，避免把床头误触当成放弃。

此页在前台时窗口保持常亮。这只服务专注，不是「充电时常亮」。

不做休息轮次。一轮结束就是结束。

进程死亡后，若结束时刻仍在未来，重开应用可以直接回到专注页。若已过，进入完成态。用户没开始过专注时，不出现残留页。

## 仪式倒计时

一条纪念日：

| 字段 | 说明 |
|------|------|
| `id` | UUID |
| `title` | 1–20 字 |
| `kind` | `solar_once`、`solar_yearly`、`lunar_yearly` |
| 阳历日期 | 一次性用年月日；每年用月和日 |
| 农历日期 | 月 1–12、日 1–30、是否闰月 |
| `message` | 到点后的一句，默认为「到了」，最长 20 字 |
| `pinned` | 是否置顶。全局最多一条 |

时区用设备当前本地时区。存储里不写死一条旅行时区。

列表上限 30。超过则拒绝新增并说明。

### 下一次发生

纯函数，输入「今天」和一条纪念日，输出下一次本地日期、状态（未来、今天、已过、找不到）。

规则：

- 比较只看本地日期，不看时分。今天该发生，状态是今天，剩余 0 天。
- 阳历每年的 2 月 29 日：只落在真正有 2 月 29 日的年份，不改到 2 月 28 日。
- 农历每年：月、日、闰月标志三者都相同才算命中。普通四月不匹配闰四月。闰四月不匹配普通四月。
- 某一年没有这个闰月，或该月没有这个日（例如小月没有三十）：跳过这一年，继续向后找。不改成廿九或三十。
- 向后最多找 20 年。仍没有则状态为找不到，界面写「近期没有这一天」，不要崩溃。
- 阳历一次性日期早于今天：状态已过。

添加时不要先存成一张空表再让用户自己心算。月、日、闰月每变一次，就用「下一次发生」算出预览，写在表单旁，例如「下次是 2027年5月28日」。若今年没有这个闰月，预览写成「今年没有这个闰月，下次是 {公历日期}」。某些年没有这一天时，预览说明会顺延。状态为找不到时，不启用保存，并写「近期没有这一天」。

库认为完全不可能的「月 + 闰月」不能留在可选结果里。可能存在、但有些年缺失的组合允许保存。

我们的模型用正数月份加 `leap` 布尔。传给 `cn.6tail:lunar` 时再换成该库要求的月份表示。不要把负月份写进 JSON。

钟面条用置顶项。全屏仪式从纪念日条或列表进入。未置顶的项目不占用钟面。

全屏按剩余时间分三种，纯函数决定，输入是当前时刻和下一次本地日期的开始：

| 模式 | 条件 | 画面 |
|------|------|------|
| 天数 | 剩余不少于 24 小时 | 标题和下一次公历日期在上方，小字。下方是天数页片：1–9 一位，10–99 两位一块，100 以上按两位分组且不补前导零。不显示时分秒 |
| 时钟 | 剩余少于 24 小时，且还没到点 | 标题留在上方。下面换成时、分、秒三块页片。进入这一模式时直接切换，不做额外转场 |
| 完成 | 到点 | 页片翻到 0 后让开，只留 `message`，居中。不播视频，不放烟花 |

停在完成态，直到用户离开。不放彩纸，不发通知，不自动再来一年。每年重复的项目下一年会自己出现在「下一次」里；完成页不负责跳年。

天数模式在本地午夜跨过一天时，只翻天数。时钟模式才允许每秒翻秒位。

已过的一次性项目留在列表，标记「已过」，不能再置顶。若它原先置顶，自动取消置顶。用户可以删除。

### 必须有测试的样例

测试固定「今天」，不读系统时钟。

| 今天 | 纪念日 | 期望 |
|------|--------|------|
| 2026-01-01 | 阳历每年 2 月 29 日 | 下一次是 2028-02-29 |
| 2028-02-29 | 阳历每年 2 月 29 日 | 今天 |
| 2026-03-01 | 阳历一次 2026-01-01 | 已过 |
| 由库算出的某个普通四月廿一的公历日 | 农历每年四月廿一，非闰 | 命中该日，且不命中同年的闰四月（若有） |
| 由库算出的某个闰月生日的公历日 | 农历每年同一闰月同一日 | 命中；普通月的同月同日不命中 |

## 设置信息架构

- 显示：小时制、主题、显示日期
- 天气：开关、城市、使用当前位置
- 防烧屏：开关、无操作时长、运行时长
- 纪念日：列表、添加、置顶、删除

专注不放在设置分组里，它从钟面控制层进入。

每个分组在对应里程碑之前不要出现。M0 的设置页可以是空状态或只有占位说明。

## 从 FliTik 借来的

FliTik（<https://www.flitik.com/>）是场景和界面的参考，不是功能清单。

借这些：

- 钟面几乎是空的。日期一行，居中，放在页片上方。
- 小时两位一块页片，分钟两位一块页片。竖屏上下叠，横屏并排。
- 专注和仪式的时钟模式沿用同一套页片，旁边不留第二套信息。
- 主题是同一套翻折的不同外观。v1 先做墨黑翻页和灯管。设置用大预览选择，而不是一串名字。

不借这些，并写在后续里程碑里：照片或网络背景、自由取色、常驻秒页片、白噪音和波形、语音报时、庆祝视频、账号、桌面小组件、专注统计和排行、正计时。它的防烧屏按周期循环；我们仍然是一轮然后停住。

## 动画预算

主屏在分钟之间保持静止，除了防烧屏开启时的慢漂移。灯管的亮起发生在换分，不循环。不要用呼吸光、粒子或秒点来「让界面活着」。秒级翻页只在专注页，以及仪式的时钟模式。离开页面就停。
