# ScreenClock

## 一句话

一部放在床头或桌上的全屏时钟：时间、天气和重要日子共用同一套翻页物件，手机和平板、竖屏和横屏都是这块钟面的不同摆法。

## 为谁做

一个人把设备放下之后仍然看得清的时钟。手机竖着用，平板横着摊在桌上。它不是闹钟，也不是天气应用。

## v1 要有的能力

1. 手机与平板、竖屏与横屏共用一套钟面，信息槽按宽度重排。
2. 两套主题。默认翻页：两位一块页片，配色「墨黑」，翻折参考 FlipClock。第二套是灯管：换分时亮一下，分钟之间保持暗。
3. 小时制：跟随系统、12 小时、24 小时。
4. 天气一行，可关。关了就不请求网络。
5. 防烧屏：无操作达到设定时长后，屏保跑一轮，时长可设。跑完停住，直到用户再碰屏幕。
6. 专注时钟：一次倒计时，全屏翻页，长按退出。
7. 仪式倒计时：生日、跨年、考试等日子。阳历一次、阳历每年、农历每年（含闰月生日）。可置顶一条。剩一天以上，全屏主角是天数；最后 24 小时才翻时分秒。
8. 翻页有机械感。主屏安静，只在数字变化时动。

M7 已完成，在 v1 之后只加了床头：夜间压低本窗口亮度、可选暖色、充电时常亮。

## 明确不做（v1）

这些想法留在 [里程碑后续](./MILESTONES.md) 里，当前不要写代码：

- 闹钟、整点报时、翻页音效、白噪音
- 专注的休息轮次、统计、通知
- 世界时钟、多城市天气、小时级预报、天气地图
- 桌面小组件、锁屏、系统级 Always On Display
- 账号、云同步、黄历宜忌、干支八字
- 亮色主题、照片背景、网络背景图、自由取色、庆祝视频、语音报时、专注排行、主屏常驻秒钟

## 术语

| 词 | 含义 |
|----|------|
| 钟面 | 平时显示时间的全屏主界面 |
| 信息槽 | 时间、日期、天气、纪念日条。主题只负责摆放，不自己发明数据 |
| 控制层 | 点一下钟面后短暂出现的设置、专注、纪念日入口 |
| 屏保 | 防烧屏的一轮缓慢移动。一次闲置只跑一轮 |
| 无操作时长 | 用户口中的「误操作时长」：多久没人碰屏幕，就启动一轮屏保 |
| 仪式 | 某个日子的全屏倒计时。不少于 24 小时显示天数，最后 24 小时才翻时分秒 |
| 置顶 | 钟面上那一条纪念日。同时只有一条 |

## 给 Agent 的硬约束

- 编码从 M0 开始，且要等用户明确要求开工。
- 农历用 `cn.6tail:lunar`（MIT，当前文档编写时最新为 1.7.7）。升级小版本可以，换库要先改本文和设计文档。
- 翻页外观参考 FlipClock，用 Compose 自己画。不要把该项目的 `flipclock.ttf` 或 SDL 源码放进仓库。
- 天气只用 Open-Meteo 的公开接口，不放密钥。关于页注明来源。
- 权限、主机和失败表现以 [`.ai/03_SECURITY.md`](./03_SECURITY.md) 为准。
