# ScreenClock

放在床头或桌上的全屏时钟。手机和平板、竖屏和横屏都是同一块深色钟面，时间用大数字，其余信息尽量少。

点空白处，底部出现「设置」「专注」「纪念日」，大约 4 秒后收起。再点空白也可以收起。

最低系统是 Android 8.0。没有账号，也没有应用商店页面。想装的话，按文末的方式自己编译。

## 钟面

设置的「显示」里有两套主题，用钟面预览选择：

- **翻页**：小时一块页片，分钟一块页片。数字变化时，页片从中间翻过去。竖屏上下排列，横屏排成一行。
- **灯管**：暗色数字。每到新的一分钟亮一下，然后回到暗。

小时制可以跟随系统，也可以固定成 12 小时或 24 小时。12 小时制时，上午或下午写在页片旁边。

日期默认显示在时间上方，可以关掉。当天是法定休息日时，日期后面会带上节日名。主屏不显示秒。

## 天气

默认关闭。打开后可以搜索一个城市，或使用一次大致位置。时间下方会显示现象和温度。屏幕较宽时，还会显示当天的最高和最低温度。

天气数据来自 [Open-Meteo](https://open-meteo.com/)。关掉之后不再访问网络。没找到城市，或暂时拿不到数据时，钟面上不显示天气。

## 防烧屏

默认关闭。打开后有两项时间：多久没有碰到屏幕才开始，以及这一轮移动多久。

到时后，钟面在屏幕里缓慢移动一轮，然后停住，不会马上再来一轮。点一下屏幕，移动停止，并重新计算下一次。

正在看专注或仪式时，防烧屏不会开始。

## 专注

从钟面底部的「专注」进入。可以选 25 分钟、50 分钟，或自己填 1 到 180 分钟。

倒计时占满屏幕。不到 1 小时显示分和秒，满 1 小时显示时、分、秒。这一页没有日期、天气和纪念日。倒计时和结束画面会让屏幕保持常亮。还在选择时长时，不会因此常亮。

想提前结束，按住大约半秒。到 0 之后停住，点一下回到钟面。中途关掉应用再打开，只要结束时刻还没到，倒计时还在。

## 纪念日

最多保存 30 条，可以是这三种：

- 阳历的某一天，只过一次
- 阳历的每年
- 农历的每年，可以指定闰月

添加的时候能看到下一次对应的公历日期。可以置顶一条，它出现在钟面下方。点这一条，或从列表打开，会进入全屏：

- 距离不少于 24 小时：只显示还有多少天
- 最后 24 小时：翻时、分、秒
- 到了当天零点：只留下你写的那句话

这一页不会为了倒计时一直亮着屏幕。返回会回到刚才进来的地方。关掉应用再打开时，不会停在这一页，置顶的那一条还在钟面上。

删除马上生效。只过一次的日子过了以后，会留在列表里并标成已过，不能再置顶。

## 夜间

在设置的「夜间」里，下面几项默认都关着。

- **夜间变暗**：在设定的钟点之间，只把本应用的这块屏幕压暗，不改系统亮度。时间段可以跨过午夜。开始和结束设成同一个钟点时，不会变暗。
- **暖色**：只在正在变暗的时候，给画面加一层暖色。
- **充电时常亮**：插着电源时保持屏幕常亮，充满但还插着也算。这和专注自己的常亮是分开的。

## 权限与数据

| 权限 | 何时使用 |
|------|----------|
| 网络 | 天气开着，并且已经有城市，或正在搜索城市 |
| 大致位置 | 只有打开「使用当前位置」时才询问 |

设置和纪念日都保存在这台设备上。没有通知，没有闹钟，也不会上传账号数据。

## 自己编译

需要 JDK 17，以及 Android SDK 里的平台 `android-37.0` 和 Build-Tools `36.0.0`。在项目根目录新建 `local.properties`，写入本机 SDK 路径：

```
sdk.dir=/path/to/Android/sdk
```

然后执行：

```bash
./gradlew :app:assembleDebug
```

安装包在 `app/build/outputs/apk/debug/app-debug.apk`。
